# Building My GitHub Profile

**Date:** 2026-07-23  
**Topic:** GitHub Profile and Development Journal  
**Status:** Completed

## What I Worked On

I redesigned and organized my GitHub profile to better represent my professional experience, current learning path, and personal interests.

I also created the `willvcr-dev-journal` repository to document my progress in web development, WordPress, automation, and technology.

## What I Learned

- How a special profile repository controls the README displayed on a GitHub profile.
- How to create and edit Markdown files directly on GitHub.
- How to upload and display a custom banner in a README.
- How to organize content using headings, lists, links, images, and badges.
- How commits document meaningful changes in a repository.
- How to create folders by including `/` in a new file path.
- How to pin repositories that best represent my current work.

## Challenges

At first, some GitHub navigation options were not immediately clear. I also needed to understand the difference between viewing a repository, viewing a previous commit, and editing the current version of a file.

Creating nested folders directly from the GitHub editor was another new part of the process.

## Solution

I worked through the process step by step, previewing each Markdown change before committing it.

I used descriptive commit messages and organized the journal into folders by year and month so future entries will remain easy to find.
