# Bilingual Web Design Brief

Reusable client questionnaire for collecting the business information,
content, design preferences, technical requirements, budget, and timeline
needed before starting a website project.

## Available Versions

- [English — Web Design Brief](Web_Design_Brief_English.docx)
- [Español — Brief de Diseño Web](Brief_de_Diseno_Web_Espanol.docx)

## Important

Do not include passwords or sensitive access credentials in these documents.
Credentials should be shared through a secure method.
